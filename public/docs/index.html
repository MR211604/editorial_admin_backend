    Auth

    Endpoints de autenticación (login, renovación de token y logout). Usa JWT en el header: Authorization: Bearer {token}.

    Iniciar sesión

    Autentica con credenciales y devuelve un JWT (Bearer).

    Este endpoint no requiere autenticación previa.

    Example request:

    curl -X POST "http://localhost/api/auth/login" \
    -H "Accept: application/json" \
    -d "token"="eveniet" \
        -d "password"="eveniet" 
    var settings = {
    "async": true,
    "crossDomain": true,
    "url": "http://localhost/api/auth/login",
    "method": "POST",
    "data": {
        "token": "eveniet",
        "password": "eveniet"
    },
    "headers": {
        "accept": "application/json"
    }
}

$.ajax(settings).done(function (response) {
    console.log(response);
});

    Example response:

    {
    "ok": true,
    "message": "Usuario conectado correctamente",
    "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9.eyJpc3MiOiJodHRwOi8vbG9jYWxob3N.....",
    "user": {
        "id": 2,
        "name": "testnameupdate",
        "active": 1,
        "join_date": "2025-06-29 19:42:59",
        "last_login_date": "2025-10-23 10:34:31",
